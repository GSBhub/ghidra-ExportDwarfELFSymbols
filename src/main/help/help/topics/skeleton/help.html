ExportDwarfELFSymbols

ExportDwarfELFSymbols is a Ghidra script that generates a minimal ELF file containing only DWARF function symbols derived from Ghidra's analysis of a loaded program. The output ELF is intended to be loaded into GDB via the symbol-file command to enable proper stack unwinding (nexti) on targets with non-standard binary formats, such as console ROMs or emulator GDB stubs.

Usage

  1. Open a program in Ghidra and ensure it has been analyzed.
  2. Run the ExportDwarfELFSymbols script from the Script Manager.
  3. When prompted, choose an output file path for the generated ELF.
  4. Load the resulting ELF into GDB: (gdb) symbol-file /path/to/output.elf

What it generates

The output is an ET_DYN ELF with no program headers. It contains a single DW_TAG_compile_unit with one DW_TAG_subprogram DIE per function found in the Ghidra program. Each function DIE carries:

  • DW_AT_name and DW_AT_linkage_name — the function name as known to Ghidra
  • DW_AT_low_pc / DW_AT_high_pc — the function's address range
  • DW_AT_frame_base using DW_OP_call_frame_cfa for stack unwinding

Supported architectures

The ELF machine type and DWARF ABI are automatically selected from the program's language: ARM, AArch64, PowerPC (32/64), MIPS, x86, and x86-64. Endianness and pointer width are also derived from the program's language descriptor.

Prerequisites

The native libdwarf shared library must be present in the appropriate os/<platform>/ directory and that directory must be on Ghidra's plugin path (Edit → Plugin Path). The library is built via CMake from the bundled libdwarf/ submodule.
